Day 38: Typing Speed Studio

A single-page, self-contained typing speed & accuracy trainer inspired by modern platforms like Monkeytype — built with vanilla HTML/CSS/JS, no frameworks or external dependencies.

Features:

8 typing modes: Time (15/30/60/120s), Word Count (25/50/100/250), Quote, Programming (JS, Python, HTML, CSS, Java, C++, SQL), Custom Text, Adaptive (auto-adjusts difficulty), Focus (single-line view), Zen (untimed)
Category-driven passage generation: General, Academic, Business, Medical, Legal, Creative — no repeated/hardcoded text across modes
Live stats: WPM, Raw WPM, CPM, Accuracy, elapsed/remaining time, mistake count, streak, real-time progress
Post-session analytics dashboard: WPM & accuracy graphs (inline SVG), consistency score, char breakdown (correct/incorrect/extra/missed), error heatmap of mistyped keys, percentile estimate, personal-best detection, achievement badges, written performance summary
Session history, streaks, and personal records — persisted via localStorage, no account required
Sound effects (WebAudio, no assets), keyboard shortcuts (Tab/Esc), pause-resume, 3 themes, adjustable font size, responsive + accessible design

Stack: Pure HTML/CSS/JS — single file, zero dependencies.
