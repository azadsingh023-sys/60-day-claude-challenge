How This Pipeline Works

Agent Responsibilities

  • Planner — reads the brief and produces a creative strategy: angles, hooks, and a rubric emphasis before any copy is written.
  • Executor — writes the first full draft of all ad variants per the plan.
  • Evaluator — scores the current draft 0–10 against the rubric (hook, clarity, CTA, persuasion), every round, live.
  • Critic — gives qualitative, specific critique on what's weak and why, independent of the numeric score.
  • Improver — rewrites the draft using the prior evaluation + critique as direct input.
  • Memory Manager — logs what changed and why each round, so later rounds don't repeat undone mistakes.
  • Final Reviewer — once a stop condition fires, polishes and formats the final deliverable and writes the executive summary.

How the Stop-Check Governs Flow

  • Every round: Evaluator scores the current draft → Critic critiques it → Improver rewrites it using both.
  • After each round the score and delta (vs. previous round) are recorded in a running history array.
  • Stop-check runs in order: (1) plateau — improvement < 0.3 for 2 consecutive rounds, (2) threshold — score crosses target (disabled in plateau-only mode), (3) hard cap — safety fallback only.
  • Whichever condition fires first ends the loop and branches execution to the Final Reviewer instead of another Improver pass.
  • The exact reason is logged and shown in the final summary — nothing is hidden.

Extending This System

Ideas to Extend

  • Add a Safety Monitor agent that screens every draft for policy/brand violations before it reaches the Evaluator.
  • Add an A/B Predictor agent that estimates relative CTR between variants using historical ad performance heuristics.
  • Persist memory across sessions (localStorage/DB) so the Planner learns brand voice over many campaigns.
  • Add human-in-the-loop approval as an optional extra stop condition ("await approval" branch).
  • Swap the rubric per platform automatically (character limits for Google Ads vs. visual-first for Instagram).

Prompts to Build More Advanced Systems

  • "Add a Safety Monitor agent that runs in parallel with the Evaluator every round and can force an early stop."
  • "Turn this into a multi-campaign system that runs several briefs in parallel and ranks the outputs."
  • "Add persistent memory so the Planner's strategy improves across multiple separate runs, not just within one."
  • "Replace the plateau-only stop with a configurable multi-condition stop the user can tune via the UI."
