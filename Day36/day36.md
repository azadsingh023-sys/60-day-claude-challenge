Day 36: Cognitive Pattern Explorer

Built a single-file, offline-first psychology-inspired self-reflection
web app using vanilla HTML/CSS/JS (no frameworks).

Features:
- Calm/Stress ambient mode toggle
- Chapter 1: scenario-based thinking-style discovery
- Chapter 2: draggable priority-ranking cards (drag, touch, keyboard)
- Chapter 3: draggable timeline mapping (instinct → deliberation)
- Final Reflection Journal with animated % breakdown across 5 thinking
  tendencies (Analytical, Emotional Intuitive, Overthinking Loop,
  Action-First, Balanced Reflective)
- Full keyboard accessibility, ARIA labels, prefers-reduced-motion support
- Responsive layout, smooth transitions, ambient background animation

Key learning: designing self-reflection UX responsibly — reflective
phrasing ("you often...", "this suggests...") instead of diagnostic
labels, since this is educational only, not a clinical tool.

Tech: single HTML file, vanilla JS, native drag-and-drop with touch
fallback, zero dependencies, works fully offline.
