## Day 37 — Task Compass

Built a single-file HTML/CSS/JS management simulation game (no frameworks) 
that teaches organizational thinking — ownership, delegation, collaboration, 
and workflow — through a Tech Company scenario set.

**Stages:**
1. Who Owns This? — drag a role card into the ownership slot for a task
2. Task Routing — build the correct handoff sequence across teams
3. Collaboration Challenge — assign up to 4 roles to complex, org-wide problems

**Features:**
- Drag-and-drop + tap-to-select role cards (8 roles: FE, BE, QA, PM, UX, CS, EM, Data)
- Animated task-flow visualization between stages
- Radar chart scoring (Ownership / Delegation / Collaboration / Workflow Thinking)
- End-of-game reflection summary instead of a raw score
- Fully offline — vanilla HTML/CSS/JS, no external libraries

**Stack:** HTML, CSS, Vanilla JavaScript (Canvas for radar chart)
