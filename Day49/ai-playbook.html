What this tool is
This is a personal library of reusable AI prompt workflows, built around your network engineering and ITSM work — things like writing incident summaries, drafting VLAN/switch configs, and working through root-cause analysis. Instead of retyping instructions to Claude every time, you save a workflow once and reuse it with different details filled in.

Workflows is your saved library. The Prompt Builder lets you assemble a one-off prompt from building blocks (role, context, constraints, etc.) with a live preview. The Loop Builder turns a prompt into a self-checking, repeating instruction — useful when you want AI to keep refining something against a goal until it's done. Everything is saved only on this device (local storage) — nothing is uploaded anywhere.

What is this playbook?
A quick tour of every section.

Dashboard

An overview of your saved workflows and a set of starter templates for network engineering / ITSM tasks, ready to use or customize.

Workflows

Your full library of saved prompt templates. Search by name, filter by category, star your favorites, duplicate one as a starting point for a variant, or edit and delete freely. Everything is stored only in this browser (local storage).

Prompt Builder

Build a one-off prompt piece by piece: role (who the AI should act as), objective (the task), context, constraints, reasoning strategy (how it should think through the problem), output format, tone, examples, and quality checks. Add the blocks you need, fill them in, and the finished prompt assembles itself on the right in real time. Save it as a workflow to reuse later.

Loop Builder

For tasks where you want AI to keep improving an answer on its own: define the goal, how it should judge its own work (evaluation criteria), how it should improve between attempts, when it should stop, and any safety limits (like a max number of attempts). This wraps your prompt in an instruction to self-check and iterate.

Your data

Workflows are saved in this browser's local storage — they won't sync across devices. Use "Export data" in the sidebar to save a backup file, and "Import data" to restore it elsewhere.
