Day 44: LinkedIn Profile Roast & Rebuild

Built an interactive HTML tool that audits a LinkedIn profile section-by-section (headline, About, experience, skills) and scores it out of 100, then generates a full rewrite with three headline options, a restructured About section (hook → story → proof → CTA), before/after experience bullets, and prioritized skill recommendations.

Key features:

Section-by-section scorecard with specific "recruiter reaction" feedback
Before/after comparison table with scoring deltas
7-day LinkedIn activation plan (post drafts, connection templates, engagement formula)
Shareable "what I learned" summary card
Pure HTML/CSS interactivity — no JavaScript dependencies (tabs via radio-input CSS, accordion via native <details>/<summary>) for maximum compatibility across viewers

Stack: HTML, CSS (no JS)
Prompt design note: structured output into 5 clearly separated deliverables (roast, rebuild, scorecard, plan, summary) rather than one long response — kept each part reviewable on its own.
