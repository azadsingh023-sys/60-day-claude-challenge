Day 39 — PDF Splitter & Merger

Single-page, client-side PDF utility. No backend, no file uploads — everything runs in the browser.

Features

Split: live page thumbnails, split by custom ranges, every N pages, split-after-page, or extract selected pages (combined or one-per-page)
Merge: drag-and-drop multiple PDFs, drag-to-reorder file list, live file/page count summary
Inline range validation with clear error highlighting
Multi-file split output bundled into a downloadable ZIP (hand-written ZIP writer, no extra library)
Dark mode, keyboard navigation, focus states, reduced-motion support

Stack: HTML/CSS/JS, pdf-lib for document manipulation, pdf.js for thumbnail rendering — both loaded via CDN, cached for offline use after first load.

File: pdf-splitter-merger.html
