Day 42/60 - Personal Financial Command Center

Built a single-page HTML/CSS/JS financial dashboard for a
salaried household — no external libraries, fully offline.

Features:
- Overview dashboard (income, expenses, surplus, savings rate)
- Income & 12-month cash flow trend (canvas charts)
- Expense tracker with 50/30/20 budget rule check
- Loan/EMI tracker with avalanche payoff order + DTI health
- Investment portfolio with allocation + 10-yr growth projection
- Goals tracker + retirement corpus estimator
- Subscription tracker
- Calculators: SIP, EMI, emergency fund, loan prepayment impact
- What-If simulator (live sliders for expense cuts, SIP increase, prepayment)
- Financial health score (0-100) with AI-style recommendations
- Dark mode, localStorage persistence, printable report, responsive UI

Stack: Vanilla HTML/CSS/JS, canvas-based charts, no dependencies.
