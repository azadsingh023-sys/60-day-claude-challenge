Day 35: Prompt Puzzle 🧩

Built a single-file HTML/CSS/JS gamified learning app that teaches AI prompting best practices through play.

What I built:

6 randomized Business/Productivity scenarios (Beginner difficulty)
3 challenge types: Build the Prompt, Clean the Prompt, Choose the Best Prompt
Live scoring system: Accuracy, Time, Moves, Wrong Placements, Hints Used, Optimization Bonus
Full Prompt Performance Report: Score, Rank (S–D), Prompt DNA visualization, personalized feedback, next milestone
Drag-and-drop interactions, hover states, floating toast notifications, confetti on completion
Fully offline — zero dependencies, works by just opening the HTML file

Key takeaway: Reinforced that effective prompts follow a Role + Task + Constraints + Format pattern — and that over-engineered prompts often underperform simple, well-structured ones.

Tech: Vanilla HTML/CSS/JS, native Drag & Drop API, Canvas (confetti), no build step.
