🎯 Goals for the Next 60 Days
Build a daily AI habit — use Claude with intention every day, not just when something breaks.
Apply AI to ITSM & IT Ops workflows — explore how Claude can help with incident documentation, process writing, runbooks, post-incident reviews, and ServiceNow-related workflows.
Level up my prompting skills — move from basic Q&A prompts to structured, reusable prompt templates for recurring IT Ops tasks.
Explore AI beyond the day job — use Claude for learning, career planning, and personal projects (not just IT tickets).
Document everything publicly — screenshot and commit daily progress here, building a visible record of growth.
Identify where AI fits into my career path — figure out whether that's deeper into ITSM/AIOps, automation, or a broader AI-adjacent IT role.
Finish strong on Day 60 — with a portfolio of real examples, a sharper AI skillset, and a clear next step for how I keep using this going forward.
📅 How This Repo Works
Each day, I add a screenshot of that day's Claude work to the /screenshots folder.
Each screenshot is committed with a short message (e.g., Day 12: incident postmortem template).
I'll periodically update this README with highlights, lessons learned, and links to standout days.
