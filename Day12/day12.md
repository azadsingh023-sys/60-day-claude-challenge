# Day 12/60 — Build Your Complete Job Search & Personal Branding Toolkit

## 🎯 Goal
Use Claude to convert a single resume into a complete, ready-to-send job search and personal branding toolkit — tailored to a specific target job description.

## 🛠️ What I Built
Gave Claude my resume + a target job posting (IT Service Manager / Incident Manager) and asked it to act as a recruiter, hiring manager, career coach, and personal branding consultant simultaneously. It generated:

1. ATS-friendly cover letter (350–450 words)
2. Recruiter outreach email
3. Hiring manager email
4. LinkedIn connection request (under 300 characters)
5. Referral request message
6. 5-day follow-up email
7. 30-second professional introduction
8. Top 10 best-fit job titles
9. Key strengths recruiters will notice
10. Skill gap analysis + learning roadmap
11. Personal brand summary (UVP, positioning statement, recruiter headline)
12. Interview talking points

## 💡 Key Takeaway
The most valuable section wasn't the writing — it was the skill gap analysis. It compared my resume directly against the job description and flagged specific missing tools (PagerDuty, Datadog/Centreon/Pingdom) and underrepresented experience (formal Problem Management/CAPA ownership), then gave a concrete 60–90 day roadmap to close those gaps.

## 🔁 How to Reuse This
Prompt structure that worked well:
- Paste resume + target JD
- Ask Claude to role-play as recruiter + hiring manager + career coach + branding consultant
- Explicitly request each output as a numbered section (cover letter, emails, LinkedIn message, gap analysis, etc.)
- Ask for quantified, ATS-friendly, non-generic language

## 📌 Next Steps
- Close the flagged skill gaps (PagerDuty fundamentals, a monitoring platform, formal Problem Management training)
- Reframe resume bullets with quantified metrics (SLA %, ticket volume)
- Reuse this toolkit template for future target roles
